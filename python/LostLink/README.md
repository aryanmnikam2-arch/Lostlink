# LostLink – Campus Lost & Found

## Overview
LostLink is a starter web application for reporting and searching lost/found items on a campus.

## Current features
- Report a lost or found item
- Store reports in SQLite
- Search by item name, category, location or description
- View item status

## Planned features
- User registration/login
- Claim management
- Match scoring
- Admin dashboard
- Image uploads
- Better validation and testing

## Technologies
- Python
- Flask
- SQLite
- HTML/CSS
- pytest

## Run
1. Install Python.
2. Open this folder in a terminal.
3. Run `pip install -r requirements.txt`.
4. Run `python app.py`.
5. Open the local Flask address shown in the terminal.

## Testing
Run `pytest`.
